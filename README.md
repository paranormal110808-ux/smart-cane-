# Smart Cane

An Arduino-based assistive device designed to detect obstacles and provide feedback to the user.

## About the Project

This project is a prototype of a smart cane designed to help visually impaired users detect obstacles in their path.

The cane uses sensors connected to an Arduino to detect nearby objects and provide feedback to the user.

## Features

- Obstacle detection using sensors
- Arduino-based control system
- Real-time feedback
- Designed as a low-cost prototype

## Components

- Arduino Uno
- Ultrasonic sensor
- Buzzer
- Breadboard
- Jumper wires

## How It Works

The sensor detects objects in front of the cane and sends the distance information to the Arduino.

The Arduino processes this information and activates the feedback mechanism when an obstacle is detected.
